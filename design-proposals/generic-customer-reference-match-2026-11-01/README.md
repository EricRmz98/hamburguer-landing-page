# Prueba visual guiada directamente por la referencia

El usuario pidió dejar de aplicar las especificaciones de las iteraciones anteriores y aproximar directamente los píxeles de su última imagen. Se utilizó la herramienta integrada image_gen con la fotografía como referencia principal, seleccionando el muñeco de pie con brazos relajados, segundo desde la izquierda.

Se generó una primera prueba y se hizo una corrección dirigida al tamaño de la cabeza para aproximar su relación con el cuerpo en la foto. El resultado seleccionado está en `sprite-reference-match.png`. Es una propuesta generada visualmente, no una extracción literal ni una matriz nativa de píxeles del juego; no se garantiza igualdad entre los píxeles de la foto y los del resultado.

Las instrucciones utilizadas están en `prompts.txt`. La fotografía original está en `reference.png`. No se modificó el juego ni se sustituyeron sprites activos.
